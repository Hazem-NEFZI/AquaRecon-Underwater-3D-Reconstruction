What the pipeline does
SIFT / RootSIFT descriptors → exhaustive matching → geometric verification → incremental structure from motion → bundle adjustment → explicit point filtering. Sparse points require at least three observations and mean reprojection error ≤ 2 px.

Experimental dense stereo rectifies adjacent views, uses SGBM, and rejects inconsistent, textureless and invalid pixels. A neighbourhood-density filter is applied for display. Unobserved holes remain holes.
Engineering boundaries
This is an inspection research prototype, not a certified measurement system. The archive has no supplied calibration, ground-truth surface, IMU or scale reference. Each run estimates a shared radial camera model. Refraction is not modelled explicitly.

Different runs have independent coordinate frames. Dense clouds are pairwise estimates, not globally fused surfaces. Corrosion, cracks and structural integrity are not automatically assessed. Real deployment requires underwater calibration and surveyed reference measurements.
